# WRTG 316: research proposal and paper

This folder holds my proposal and research paper for WRTG 316 (Technical Writing, BYU,
Fall 2026). The topic is the lab's robot-arm work on the AgileX PiPER, and the paper may
later feed into a manuscript.

## What's here

- **`README.md`**: this page. It is the only file published while the course is running.
- **Drafts** (`.tex`, `.bib`, figures): kept on my computer until each assignment is turned
  in, then published here.
- **`Private/`**: course materials and correspondence. Never published.

## AI use

I use AI tools in this project with my instructor's approval, given by email on
October 28, 2026. The approval covers two uses:

- **Edison Scientific** queries, as one way of finding sources.
- **Claude Code**, in "steering sessions" where I direct the drafting in real time and decide
  what to keep, change, reorder or rewrite.

To keep that use transparent, my instructor suggested making the AI sessions public. Each
session is posted as a GitHub issue in this repository, so anyone can see what I asked for
and what the AI produced.

## Protocol

1. **One issue per session.** Each Claude session on the proposal or the paper gets its own
   issue, named in order, starting from 0:
   - `WRTG-Proposal-0`, `WRTG-Proposal-1`, …
   - `WRTG-Paper-0`, `WRTG-Paper-1`, …
2. **Post the whole session.** Export the transcript (`/export` in Claude Code) and paste it
   into the issue. Note which drafts or commits came out of the session.
3. **Check before posting.** Remove passwords, API keys and anything from `Private/`, and
   say in the issue what was removed.
4. **Check every source myself.** AI tools, including Edison, can attribute a claim to the
   wrong paper. I read the original source before citing it.
5. **Disclose in the submission.** Each assignment I turn in says how AI was used and links
   to its session issues.

\section{Background}

This second demo section shows a list and an equation, so we can check that the preview
updates when only this file changes.

\begin{itemize}
  \item The PDF rebuilds whenever a \texttt{.tex} file is saved.
  \item Ctrl+click in the PDF jumps to the matching line of source.
\end{itemize}

A numbered equation:
\begin{equation}
  \tau = J(\mathbf{q})^{\mathsf{T}} \mathbf{F}
  \label{eq:demo}
\end{equation}
Equation~\eqref{eq:demo} is referenced here by its label.
